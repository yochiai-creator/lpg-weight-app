# LPG容器 質量転記アプリ

## リポジトリ構成

ルートの `.clasp.json` が `rootDir: "gas"` を指しているので、`clasp pull` / `clasp push` がそのまま使える。

| `gas/Setup.js` | 初期セットアップ |

| `tools/syntax_check.js` | `gas/*.js` の構文チェック。`npm run check` |
| `setup/LPG容器_質量入力.xlsx` | セットアップ用スプレッドシート（書式・管理シート入り） |


高圧ガス容器検査の質量計測を、iPad＋外付けテンキーで入力し、**検査成績表（元Excel様式）へ自動転記**する
Google Apps Script（スプレッドシート＋バインドスクリプト）です。
AppSheet版の操作マニュアル（容器番号と質量の2つだけ入力）と同じ流れで、紙への手書き・清書をなくします。

## 現場での流れ

0. **入力者を選ぶ**（端末ごとに1回。次回からは記憶）: 「入力者」シートに登録したスタッフ名から選び、端末名（iPad-1 など）を入れる。
   入力記録には1本ごとに「いつ・誰が（入力者）・どの端末で・何番を・何kgで」入れたかが残ります。
1. **ロット登録**（1日の最初、または切り替え時のみ）: 記号（HEP など）・組容器番号の**開始と終了**・容器区分を入れて登録。
   紙の成績表と同じ `○○001〜○○100` の100本単位に分けて、まとめてロットを作る（例: `36401〜38000` → 16ロット）。
   範囲が区切りの途中から始まっていても（例 `36485〜37943`）、その番号を含む100本単位で作る。登録済みのロットは飛ばす。
   終了を空欄にすると開始から100本の1ロットだけ作る。成績表シートは容器番号欄（001〜100、1000番目は `000`）まで自動で入る
2. **入力を始める** → 1本ごとに
   - 容器番号をテンキーで入力して `Enter`（下3桁でOK。先頭の0は不要。記録先のロットは番号から自動で決まる）
   - 質量を入力して `Enter` で保存。すぐ次の容器番号の入力になる
3. **自動納品**: 100本（欠番を含む）がそろった時点で、その場で自動的に
   - ロットを「完了」にする
   - 成績表PDFをドライブの「LPG容器 検査成績表PDF」フォルダに保存
   - 「設定」シートの送付先へ、PDFと質量データCSV（容器番号・質量・入力日時・入力者）を添付してメール送信

   入力画面に「★全数そろいました。…へ送信しました」と出ます。未入力が残っていても、ロット一覧の「完了にする」で手動で完了・送信できます。
   耐圧試験欄はアプリでは入力しません（代表容器番号には開始番号が入ります）。
   完了済みロットは一覧から「再送信」できます。

### Enterなしの自動確定（初期設定でオン）

1本10秒で流れても間に合うよう、Enterを押さずに次へ進む。

- **容器番号**: 画面に出ている桁数（例「下4桁を入力」）を打つと、その時点で記録先が決まり質量欄へ進む。
  桁数は、入力中のロットどうしで番号が重ならない最小の下桁数（3〜6桁）を自動で決める。入力画面を開いている間は減らない（ロットが完了しても打ち慣れた桁数のまま）
- **質量**: 3桁（`348`→34.8。5kg・8kgのように標準が10kg未満のロットは2桁 `68`→6.8）を打つと自動で保存して次の容器番号へ
- 入力済みの上書き・標準から外れた質量・欠番は、Enterで確定するまで止まる
- 画面の「Enterなしで自動確定」のチェックを外すと、従来どおりEnterで確定するモードになる（端末ごとに記憶）

- **質量1桁入力**（既定オン）: ロットの標準（入力済み5本以上の中央値）が決まると、標準±0.5kgの10通りは**小数第1位の1桁だけ**で保存する。
  例: 標準34.8なら範囲は34.3〜35.2で、`7`→34.7、`0`→35.0。範囲は質量欄の右上に表示。
  **範囲外のときは `.` を押してから3桁**（`.353`→35.3）。ロットの最初の5本は3桁で入力する。チェックを外すと常に3桁

- **候補ボタン**: ロットの**1本目から**、質量欄の下に10個の値がボタンで並ぶ。タップ1回で保存。
  真ん中の値は、5本以上入ればそのロットの中央値、それまでは最後に入れた値、1本目は容器区分ごとのいつもの値
  （設定シート「標準質量」: 5kg=6.8, 8kg=9.6, 20kg=16.7, 30kg=24.0, 50kg=34.8, 50kg S付=36.3。変更可）。
  そのロットで一番多い値は濃紺、2・3番目は薄い青。テンキーの1桁入力は、値がずれていても気づけるよう5本入ってから使える

- **前回±0.1ボタン**: 質量欄のすぐ上に「前回−0.1」「前回と同じ」「前回＋0.1」の3つを実際の値付きで表示。タップで保存。
  「前回」はそのロットで最後に入れた値（まだなければ標準値）
- **番号もタップで選べる**: 右側の一覧（成績表と同じ5列×20行）のマスをタップすると、その容器を選んで質量入力へ。
  入力済みのマスはもう一度タップで上書き。マス→候補ボタンの**タップ2回**で1本入力できる
- **ロットは機種（容器区分）ごと**: ロット一覧画面に「すべて・20kg・50kg…」の切り替えボタン。「すべて」は機種ごとの見出し付きで並ぶ（選んだ機種は端末ごとに記憶）。
  入力中ロットのカードの「機種を変更」で、登録後に容器区分を直せる。
  入力画面のタブも機種ごとにまとめて並ぶ。番号の記録先は機種に関係なく全ロットから自動で決まる
- **タブレット縦向きは上下配置**: 上に容器番号の表（大きめの文字）、下に番号欄とテンキー。横向きは左右配置
- **入力バー**: 容器番号が決まると、質量の入力バー（W欄・前回±0.1・候補ボタン10個・シール違い・修正）が下の入力欄の上にせり上がって出る。
  保存すると引っ込んで次の番号へ。番号を打っている間は出ないので表を広く使える
- **W表示**: 質量は刻印の表記に合わせて「W34.8」の形で表示（候補ボタン・前回±・表・メッセージ）。成績表シートは紙の様式どおり数字のみ
- **底黒（再搬入）**: ロット登録欄の「仕様」で「底黒」を選んで登録する（範囲のまとめ登録も可）。成績表は `成績表_…_底黒`、組容器番号の欄に「（底黒）」。
  底黒ロットでは容器番号を入れるだけで質量の欄に〇が付いて保存され、質量は入力しない。〇済みの容器がもう一度流れても二重には記録しない。
  入力記録の区分は「底黒」。元の通常ロットとは連動しない。入力中のロットと番号が重なる登録はできない（番号から記録先を決められないため）
- **修正（品質不良）**: ラインで品質が悪く修正に回す容器は、質量欄の下の「修正（品質不良）」ボタンで記録（欠番と同じく質量なし）。
  成績表のマスに「修正」、入力記録の区分「修正」、表のマスはオレンジ。見出しとカードに「修正 ○本」、納品メールに「修正 ○」
- **ダブり**: 入力済みの番号をもう一度入れると、メッセージ欄が赤く点滅して「⚠ ダブり」と表示し警告音2回。上書きの理由を選ぶ:
  - **ダブりとして記録**（2回流れてきた）: ＋キー／ボタン → 区分「ダブり」、表のマスは赤枠＋「W」
  - 質量の入力バーの右上の「×」で、質量を入れずにバーを閉じて容器番号の入力に戻る
  - **訂正して上書き**（入力ミスを直す）: Enter／もう一度タップ／ボタン → 区分「訂正」（印は付けない）
- **シール違い**: 質量を入れるときに「シール違い」ボタンを押すと、入力記録の備考に「シール違い」、表のマスに「シ」
- 表の見出しとロット一覧のカードに「ダブり／シール違い ○件」。入力記録から数えるので開き直しても消えない。
  納品CSVにも区分と備考が入る
- **ロット一覧はスクロール**: 入力画面のロットのタブは2段の横スクロール（今のロットが真ん中に来る。100本そろったタブは緑枠）。
  ロット一覧画面の「入力中のロット」も枠の中で縦スクロール

1本あたりのキー操作は「番号4桁＋質量1桁」の5打（標準が決まるまでは7打）。

### テンキー操作

| キー | 働き |
|---|---|
| 数字・`.` | 入力（質量は `348` と打てば 34.8、`68` なら 6.8 とみなす） |
| `Enter` | 次へ／保存 |
| `+` | 前回と同じ質量で保存 |
| `-` | 欠番として保存（成績表には「欠番」と記入） |
| `/` | 番号NG（刻印と違う）→ 実容器番号を入力。入力記録に「NG」と最初の番号が残る |
| `*` | 直前の入力を取消（上書き前の値に戻す） |
| `⌫` | 1字消す（空なら前の欄に戻る） |

NumLockがオフでも数字キーとして扱います。画面上のテンキーをタップしても同じ操作ができます。

### 誤入力を防ぐチェック

- 容器番号がどの入力中ロットの範囲にもない → エラー音と赤表示（「9」と「7」、「4」と「1」の読み違いなどを検知）
- 下3桁が複数のロットに当たる → 4桁以上での入力を促す
- 入力済みの容器番号 → 「上書きするならもう一度Enter」
- 質量が 0.1〜99.9 kg の範囲外 → 保存できない
- 質量がそのロットの標準値（入力済み5本以上の中央値）から ±0.5 kg を超える → 刻印の再確認を促し、もう一度 Enter で確定
- 右側に成績表と同じ並び（5列×20行）の進み具合を表示。未入力の番号がひと目でわかる
- 保存は裏側で順番に送信するので、通信を待たずに次の1本を入力できる。失敗すると赤表示になり「再送」できる

## 初回セットアップ

1. 新しいGoogleスプレッドシートを用意し、`高圧ガス容器検査成績表.xlsx` の「検査成績表 (001-100)」シートを取り込む。
   （書式シートと各管理シートを入れ済みの `setup/LPG容器_質量入力.xlsx` があれば、それをドライブにアップロードして
   「Googleスプレッドシートとして保存」するだけでOK）
2. このリポジトリのルートで `clasp push`（`.clasp.json` が `rootDir: "gas"` を指している）。
3. スプレッドシートを再読み込みすると、メニュー「LPG容器検査」が出るので「初期セットアップ」を実行する（初回は権限の承認が必要。
   スプレッドシート・ドライブ・メール送信・外部URL取得(PDF作成用)の権限を求められます）。
   「ロット」「入力記録」「設定」「入力者」「書式_成績表」シートができます。
4. 「設定」シートの **送付先**（納品先のメールアドレス）と、「入力者」シートにスタッフ名を入れる。
   送付先が空のあいだはメールは送られません（PDF保存と完了だけ行う）。
5. Apps Script で「デプロイ > 新しいデプロイ > ウェブアプリ」（実行ユーザー: 自分、アクセス: 組織内）。
   発行されたURLをiPadのSafariで開き、「共有 > ホーム画面に追加」しておくとアプリのように起動できます。
   URLはメニュー「LPG容器検査 > 入力画面のURLを表示」でも確認できます。

## シート構成

| シート | 内容 |
|---|---|
| ロット | ロットID（記号＋開始番号）、開始・終了番号、容器区分、状態（入力中/完了）、成績表シート名、耐圧試験の値、PDFのURL、送信日時・送信先 |
| 入力記録 | 1本ごとの入力ログ（流れた順）。記録ID・入力日時・容器番号・質量・**区分（通常／欠番／修正＝品質不良／ダブり／訂正）**・一致結果・上書き前の値・Googleアカウント・状態（有効/取消）・入力者・端末・取消日時・**備考（シール違い）**。取り消しても行は消さずに残す |
| 設定 | 納品メールの送付先・CC・自動送信する/しない・差出人名・件名・本文 |
| 入力者 | 入力画面で選べるスタッフ名 |
| 書式_成績表 | 成績表の書式（元Excelのコピー）。ロット登録のたびにこれを複製する |
| 成績表_〜 | ロットごとの検査成績表。容器番号・☑・質量（10の位／1の位／小数1位のマス）が自動で埋まる |

成績表の配置は元Excelと同じ: 質量計測は5ブロック×20行（B/H/N/T/Z列が容器番号、その右が☑と質量の各桁）、
V2 が組容器番号、H26 が代表容器番号。

## メモ

- 元Excelの「検査成績表 (901-1000)」シートは B5 が 801 になっていて、801〜900 と同じ番号が出ます。
  このアプリは書式を1枚だけ使い、容器番号を毎回書き込むので影響はありません。
- 50kg容器のシール値（W＋0.5）との照合は、刻印読み取りテストで効果があったチェックです。
  必要なら「シール値も入力して W＋0.5 と一致するか確認する」モードを追加できます。

## ロットの削除（v29）

入力中ロットのカードの「削除」で、ロット行と成績表シートを削除する。入力記録は消さずに状態を「削除」として残す。

## 起動の高速化（v32）

最後に読み込んだ一覧を端末（localStorage）に保存し、次の起動ではまずそれを表示して「前回の一覧を表示中・最新に更新しています…」を出す。サーバーから最新が届いたら置き換える。更新前にその画面で入力した分は、最新の一覧の上に重ねるので消えない。

## 入力ミスを消す（v33）

入力済みのマスをタップ（または番号を入力）→「入力を消す」。質量バーが開いているときは「この入力を消す」。底黒の〇済みマスはタップで確認して消す。成績表の質量欄を空に戻し、その容器の入力記録の有効な行をすべて「取消」（取消日時付き）にする。サーバー関数 clearEntry({lotId, serial})。

## 内容積の自動入力（v34）

設定シートの「内容積」（容器区分=リットル）の値を、成績表の N3（「内容積：」と「lit」の間）に入れる。ロット登録時と機種変更時に入る。v34より前に作った入力中ロットには、初回の起動時に1度だけ入れる（プロパティ VOLUME_FILLED）。初期値は 5kg=12, 8kg=19, 20kg=47, 30kg=71, 50kg=118, 50kg S付=118（v35で確定。v34の仮の値が入っていた設定・入力中ロットは初回起動時に置き換える。プロパティ VOLUME_FILLED=2）。

## 確認は2回押し（v36）

iPadの入力画面（GASのiframe）では confirm/alert のダイアログが出ずに処理が止まることがあるため、確認が要る操作はすべて「同じボタンをもう一度押す」（5秒以内）に変更。対象: 入力を消す／ロット削除／メール再送信／完了（未入力あり）／送信中に一覧へ戻る。結果やエラーは alert ではなく画面のメッセージ欄に出す。テストはダイアログが出たら FAIL にする。

## 表のスワイプでロット切替（v37）

入力画面の表（#grid）を左右にスワイプ、または件数の左右の ‹ › ボタンで、タブの並び順（機種ごと）に前後のロットの表へ切り替える。縦スクロールはそのまま（touch-action: pan-y）。表示の切り替えだけで、入力先は容器番号で決まる。

## 組番号を見やすく（v38）

ロットのタブと表の見出しで、記号は小さく、組（開始番号の下2桁を除いた部分。例 HEP**370**01）を太く大きく表示。タブの件数は小さな丸枠。表のマスの番号も少し大きく太く（入力済みは紺の太字）。

## グループNo（v39）

30kg・50kg・50kg S付のロットは、タブ・表の見出し・ホームのカードに「グループNo」を大きく出す。グループNo = 100本ごとの組の番号 = floor((開始番号-1)/100)+1（例 59701〜59800 → 598、37001〜37100 → 371）。それ以外の機種は開始番号をそのまま大きく出す。表のマスの番号（001〜100）は1.25倍の太字。

## 20kgのグループNo（v40）

20kgは50本ごとのグループNo: floor((番号-1)/50)%1000+1（20kg番号取り早見表どおり。1〜50=1、3001〜3050=61、49951〜50000=1000、50001〜50050=1、59701〜59750=195）。1ロットは100本のままなので「195・196」のように2つ表示。v41で5kg・8kgも20kgと同じルールに。

## 入力バーの容器番号を大きく（v42）

質量の入力バーの見出しを「HEP 37**070** の W」に（番号30px、下3桁38px、記号は小さめ）。

## 入力記録にグループNo・容器区分（v43）

入力記録の17列目「グループNo」（容器1本ごと。5/8/20kgは50本ごと、30/50kg系は100本ごと）、18列目「容器区分」。これまでの記録には初回起動時に1度だけ入れる（プロパティ LOG_GROUP_FILLED）。関数 groupNoOf_(kind, serial)。
